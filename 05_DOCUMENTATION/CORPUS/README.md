# Neo Corpus Context Layer

This directory is the **context reconstruction layer** for Neo.

Read it after the repository/SROS orientation and before asking the engineers to make architectural judgments.

## Files

- [`NEO_FULL_CORPUS_RECONSTRUCTION.md`](NEO_FULL_CORPUS_RECONSTRUCTION.md) — full synopsis of the model records, historical engineering chats, architectural discoveries, tool capabilities, contradictions, and epistemic rules.
- [`MODEL_RECORD_AND_TOOL_CAPABILITY_MATRIX.md`](MODEL_RECORD_AND_TOOL_CAPABILITY_MATRIX.md) — compact operational matrix of model roles and demonstrated capabilities.

## Required context sequence

```text
README
  ↓
Repository architecture
  ↓
SROS contracts + implementation + tests
  ↓
Engineering/system records
  ↓
ALL AI model records
  ↓
Corpus reconstruction
  ↓
Referenced implementations
  ↓
Stationary Engineer
  ↓
Non-Stationary Engineer
  ↓
Synthesis / conflict analysis
  ↓
Plan
  ↓
Verified implementation
```

## Important

The reconstruction is a synthesis. The original records remain the provenance source and should be opened when a specific claim matters.

No historical model response is automatically correct. No current implementation is automatically complete. The purpose of this layer is to prevent important context from being lost while keeping evidence levels explicit.
