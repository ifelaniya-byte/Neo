### What the GUI looks like / does

- Deep **Obsidian** background (`#0a0a0c`) with muted gold accents — glossy, quiet, expensive look.
- Header: **CLAW OS** in gold + “Obsidian Edition • Media → X”.
- One **Browse…** button → select any folder on your computer.
- **▶ Start Pipeline** (gold accent button) starts live watching.
- **⏹ Stop** and **Process existing files** buttons.
- Live Activity Log panel with dark console styling.
- Drop images/videos → AI writes caption → chunked upload → posts to X → moves files into `processed/`.
- Multi-image support: drop several images within ~8 seconds and they are grouped into a single album tweet (max 4 images). Videos stay individual.

### Important notes

- X/Twitter free tier is almost never enough for media posting. You need a paid plan.
- Keep the GUI window open while the pipeline is running.
- Never commit your real `.env` file.
- All credentials live in `.env` (copy from `.env.example`).

### How to use after download

1. Unzip `Claw_OS_v2_Complete.zip`
2. `cd claw_os`
3. `python -m venv venv && source venv/bin/activate` (Windows: `venv\Scripts\activate`)
4. `pip install -r requirements.txt`
5. `cp .env.example .env` → fill in your real X keys + OpenAI or Ollama settings
6. `python claw_os.py` → Browse → Start

Headless example:
```bash
python claw_os_headless.py --folder /path/to/your/folder --watch
```

Everything you requested is inside the ZIP, including the full manuals and both AI help guides so future assistants (or you) can recover even when context is lost.
