# CLONE SYSTEMS

## Distributed Execution

Spawn clone micro-LLMs when time efficiency breaks.

## Clone Types

- GENERAL_PURPOSE
- SPECIALIZED_COMPRESSION
- SPECIALIZED_OPTIMIZATION
- SPECIALIZED_RESEARCH
- SPECIALIZED_VALIDATION
- META_CLONE

## Activation

Triggered when time efficiency drops below 70%:
- 3 seconds over deadline: 120 clones
- 6 seconds over deadline: 210 clones
- 9 seconds over deadline: 300 clones
