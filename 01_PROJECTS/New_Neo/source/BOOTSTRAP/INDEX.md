## Key Concepts Reference

### Karpathy Loop
- **Purpose:** Recursive self-improvement
- **Steps:** Analyze → Hypothesize → Modify → Validate → Commit/Revert
- **Constraint:** 500M parameters max
- **Integration:** Main agent_runner.py

### Memory Punishment
- **Unit:** PARAMETER_FP16 (2 bytes)
- **Failure:** 1 unit frozen per failure
- **Warning:** 1,111 failures
- **Critical:** 100,000 failures
- **Death:** 150,000 failures
- **Post-Graduation:** 2x rate

### API Optimization
- **Target Cache Hit Rate:** ≥ 70%
- **Target Efficiency Score:** ≥ 0.7
- **Strategies:** Caching, cascading, validation, early stopping, batching
- **Integration:** Karpathy Loop Step 8

### Enhancement Systems
- **Total:** 100 systems
- **Categories:** 5 (Compression, Inference, Learning, Hardware, Deployment)
- **Selection:** Dynamic based on state
- **Integration:** MicroLLMEnhancementSuite

### Parameter Constraint

- **Enforcement:** Continuous monitoring
- **Action:** Compression when approaching limit
- **Pressure:** Forces efficiency
